1. Phase A: Fast-Path Algebraic Invariants

-- [Rule 1: Saturated Clue] If Target == |Unrevealed|, ∀ x ∈ N: x = 1 (FLAG MINE)
-- [Rule 2: Zero Effective] If Target == 0, ∀ x ∈ N: x = 0 (REVEAL SAFE)
-- [Rule 3: Subset Diff] If V_A ⊂ V_B => (V_B \ V_A) = T_B - T_A

2. Phase B: Exact Component Decomposition & Solution Space

For coupled multi-clue equations, the solver partitions the frontier into independent disjoint sets and calculates exact marginal probabilities:

$$P(x_i = 1 \mid \text{Board}) = \frac{\sum_{\vec{s} \in \mathcal{S}_{\text{valid}}} s_i}{|\mathcal{S}_{\text{valid}}|}$$

If $P=0.0 \implies$ 100% Deterministically Safe. If $P=1.0 \implies$ 100% Deterministic Mine.
